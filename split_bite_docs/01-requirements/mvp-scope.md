# MVP Scope

## Included in MVP
- Auth (email/password)
- Groups (create, join via invite code, view members/balances/history)
- Order creation (inside groups, with order owner)
- Item adding (price optional initially)
- Order owner finalization (fill prices, actual_total)
- Shared items (equal split)
- Multi-payer support
- Guest participants (with host mapping)
- Net balance calculation
- Persistent group ledger
- Settle up functionality
- Push notifications (order created, finalized, settlement)

## Excluded from MVP (Future)
- Custom split percentages
- Payment integrations (InstaPay, Vodafone Cash)
- Smart reminders
- Guest-to-user conversion
- Analytics
- Social login (Google, Apple)
- Receipt scanning / OCR
